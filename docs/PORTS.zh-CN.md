# 端口与安全边界

NasAnySim 将“手机访问入口”和“内部控制面”分开。公网只需要转发网页入口与 TURN 中继端口；管理接口和 host ADB 不应暴露给互联网。

## 公网转发

| 端口 | 协议 | 用途 | 是否需要 |
|---:|:---:|---|---|
| `7577` | TCP | Caddy HTTPS、PWA、远程访问入口 | 必须 |
| `3478` | UDP | TURN 连接建立 | 必须 |
| `49160-49167` | UDP | TURN relay 媒体端口段 | 通话必须 |
| `5349` | TCP | TURN TLS 中继 | 启用证书后建议放行 |

以上端口应从路由器转发到运行 NasAnySim 的主机 LAN IP。`49160-49167/UDP` 不能只开放其中一个端口；网页能打开不代表 WebRTC 媒体已经可达。

## 仅本机端口

| 端口 | 绑定 | 用途 | 公网转发 |
|---:|---|---|:---:|
| `7576` | `127.0.0.1` | 后端控制台和诊断 API | 禁止 |
| `7578` | `127.0.0.1` | Caddy 的反代目标 | 禁止 |
| `5037` | `localhost` | host ADB server | 禁止 |

部署脚本会拒绝继续使用暴露到非 loopback 地址的 ADB server。不要为了让容器“能看到 ADB”而把 `5037` 绑定到 `0.0.0.0`。

## 路由器检查顺序

1. 确认域名解析到家庭公网 IP；
2. 转发 `7577/TCP`，确认 HTTPS 页面可打开；
3. 转发 `3478/UDP` 和 `49160-49167/UDP`；
4. 证书存在时再转发 `5349/TCP`，它是蜂窝网络下更可靠的 TURN TLS 路径；
5. 从手机蜂窝网络测试，不要只在同一局域网内访问。

## 已有反向代理

当前双端实测脚本默认启动内置 Caddy，并要求 `7577` 未被占用。`NASANY_SKIP_CADDY` 不属于本轮双端验收覆盖的公开接口。若宿主机已有代理占用 `7577`，不要直接执行当前一键部署，应先单独完成代理整合并重新验收。无论采用哪种代理，都不要把 `7576`、`7578` 或 `5037` 转发到公网。
